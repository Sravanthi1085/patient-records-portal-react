# CareDesk — Patient Records Management Portal

A React + Vite front-end project for a small clinic's patient directory.

## Features
- Dashboard with total, active and follow-up patient counts
- Patient directory with search and status filtering
- Add, edit and delete patient records
- Responsive layout for desktop and mobile
- Browser localStorage persistence
- Fictional sample patient records

## Run locally
1. Install Node.js (LTS).
2. Extract this ZIP and open the project folder in VS Code.
3. Open a terminal in the project folder and run:

   ```bash
   npm install
   npm run dev
   ```

4. Open the local URL printed by Vite (usually http://localhost:5173).

## Important limitations
This is an educational demo, not a production medical system. It has no authentication, server, database, audit logging, encryption, role-based access, backups, or compliance controls. Data is stored only in the current browser. Do not enter real patient or medical information. For real deployment, add a secure backend, access controls, encryption, audit trails, backups, and applicable healthcare privacy/legal safeguards.
